# Java Parkolóház Projekt

*A program objektumorientált megközelítéssel készült és egy parkolóház működését modellezi, mely választható számú emelettel és férőhellyel rendelkezik. Mindemellett több osztály is tesztelésre került JUnit 5 tesztekkel, melyek a megbízható, helyes működést garantálják.*

## A program sajátosságai

* ### Több autótípus
  * A parkolóház képes eltárolni kis- és nagyméretű autókat is, figyelembe véve, hogy a különböző autótípusok más-más helyigénnyel rendelkeznek

* ### Preferenciás helykeresés
  * A sofőrök rendelkezhetnek preferenciákkal az emeletkre vonatkozóan, a program ezen preferenciákat figyelembe veszi és ezek alapján helyezi el az autókat a legoptimálisabb üres helyre

* ### Vizuális megjelenítés
  * A program kirajzol egy szöveges térképet a parkolóház aktuális állapotártól, ebben jelezve a kis- és nagyméretű autókat, illetve a szabad helyeket
